Conclusion
----------
The experiment does not improve the aggregate outcome over the role-specific SAM3 run. Five-frame Qwen tracking avoids the degenerate constant boxes produced by a single 30-frame request and helps choose among existing robot candidates, but it cannot recover an entity for which SAM3 produces no candidate. Exact-overlap rejection was also too brittle, so Qwen boxes are correctly retained only as a soft selector.

The next justified global experiment is to use the existing five-frame Qwen box tracks as anchors for short SAM2.1 propagation blocks. This directly tests whether box-grounded segmentation can recover missing small objects and supports without the long-horizon drift seen in the previous single-anchor SAM2 experiment. Separately, graph validation should suppress relations/actions that depend on an entity with no usable track instead of accepting hallucinated semantic output.
