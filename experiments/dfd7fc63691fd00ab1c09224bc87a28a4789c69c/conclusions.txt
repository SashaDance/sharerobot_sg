Experiment: author-released ReVIOSa-4B interaction-aware referring video segmentation
Source commit: dfd7fc63691fd00ab1c09224bc87a28a4789c69c
Scope: tracking-only comparison on the fixed 10-scene pilot; no relations, support objects, depth, or trajectories were generated.

The same global prompt requested separate subject/actor and object/target masks from each planning goal. The model was run from the authors' pinned Docker image and pinned Hugging Face checkpoint. As in the authors' evaluation code, the first actor and target tracks were used. ReVIOSa often produced a useful robot mask, but it did not produce a usable manipulated-object track in any of the ten scenes. It therefore must not replace the current SAM3/SAM2 pipeline.

9_asu_table_top_converted_externally_to_rlds__episode_103 — PARTIALLY SUCCESSFUL. The robot is tracked well. The target mask selects the table or scattered table pixels rather than the Coca-Cola can and then disappears.

Outcome count: 0 fully successful, 6 partially successful, and 4 unsuccessful.

Decision: do not integrate ReVIOSa into the unified pipeline. Its interaction formulation is relevant on paper, but the released model does not transfer reliably to low-resolution robot manipulation and cannot solve the manipulated-object grounding failure without task-specific retraining.
