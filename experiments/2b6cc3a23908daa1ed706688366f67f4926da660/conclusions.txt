Experiment: controlled boundary-only graph evidence with frozen upstream artifacts
Source commit: 2b6cc3a23908daa1ed706688366f67f4926da660
Frozen baseline: 48d934e85ddd8b93a570f647f7f5c103a0dbdd01
Outcome count: 4 fully successful, 4 partially successful, and 2 unsuccessful.

Method
------
This is a true graph-only ablation. The ten baseline scenes were copied with
filesystem reflinks, and all task specifications, tracks, masks, input frames,
DA3 outputs, and trajectories were preserved. A hash audit confirmed that all
1,040 task-specification, tracking, and mask files are byte-identical to the
baseline. Only Qwen graph inference, rendering, validation, and review indexing
were rerun. Qwen received opaque role-colored boundaries and role markers, with
no mask-area color fill.

Automated result
----------------
Graph inference, rendering, and validation completed for all ten scenes with no
failures. The controlled run reproduces the four important endpoint changes
seen in the earlier boundary experiment: Clamp, UCSD, VIOLA, and Bridge. This
confirms that these endpoint changes are caused by graph evidence rendering,
not by a changed entity specification or mask track.

Decision
--------
Do not adopt boundary-only evidence globally. It produces two clear graph
improvements (VIOLA and Bridge) and a reasonable conservative change in Clamp,
but it loses the clearly correct small-object holding state in UCSD. Restore the
filled-mask baseline as the current default. A future graph-evidence change
would need adaptive or dual-view evidence and must use the same frozen-upstream
protocol; another global opacity adjustment is not justified by these results.
