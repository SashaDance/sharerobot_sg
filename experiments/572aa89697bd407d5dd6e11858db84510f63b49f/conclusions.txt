Experiment: AgentRVOS-style no-box SAM3 track selection
Source commit: 572aa89697bd407d5dd6e11858db84510f63b49f
Comparison: 6a92f2661a2123be9ee0d61ff29257801aac002a (current best pipeline)
Outcome count: 2 fully successful, 2 partially successful, and 6 unsuccessful.

Method
------
Qwen first extracts a specific core concept and a broader noun concept for each
role, without predicting any spatial boxes. SAM3 runs both text concepts and
preserves every native candidate track. Following the central AgentRVOS idea,
Qwen then inspects colored candidate tracks over all 30 frames, classifies each
candidate as accepted or rejected, and selects at most one track per role. The
concept with more native SAM3 instances is preferred before visual selection.
The same procedure is used for every scene; there are no scene-specific rules.

This is an adaptation of the AgentRVOS paper, not a reproduction: as of this
experiment the official repository still marks inference, evaluation, and demo
code as forthcoming. Unlike the paper's iterative agent, this pilot performs a
single visual-selection pass per role and uses our fixed role ontology.

References:
https://arxiv.org/abs/2603.23489
https://github.com/cvlab-kaist/AgentRVOS

Execution and automated result
------------------------------
The committed experiment ran the fixed 10-scene, FMB-free pilot in Docker.
Qwen stayed on GPU 0 while SAM3 and DA3 used GPU 1. All automated stages
completed for all 10 scenes with valid schemas and artifacts. Total wall time,
including Qwen startup and every pipeline stage, was 1,914 seconds (31m 54s).
The mask-track selector made 36 Qwen calls taking 116.1 seconds in total, or
3.23 seconds per role on average. It used no Qwen-generated boxes.

Visual assessment by scene
--------------------------

The robot and table masks are good, but Qwen rejects both SAM3 can candidates.
The graph still describes the manipulation, but it is not grounded to a visible
manipulated-object track. The pre-existing duplicate support/target table issue
also remains.

11 UTokyo xArm Pick-and-Place / episode 12 — partially successful
The robot, white manipulated plate, and red target plate are usable, and the
stacking sequence is coherent. Qwen incorrectly rejects the valid green-table

15 DLR SARA Grid Clamp / episode 100 — unsuccessful
The agent correctly rejects SAM3's full-row clamp mask instead of accepting it
as one clamp. This is safer than the baseline, but no valid single-clamp track
remains, so the task graph has no manipulated-object grounding.

17 DLR SARA Pour / episode 55 — unsuccessful
The robot is stable, but the manipulated cup is retained for only the final
seven frames. Qwen rejects both the rear-tray initial support and the visible
white target mug. The pickup/pour graph is therefore mostly ungrounded.

18 DLR EDAN Shared Control / episode 86 — partially successful
The red mug and glass-table support are tracked well and their pickup state is
coherent. Qwen rejects the robot track, leaving every robot action without a
corresponding visible mask.

19 UCSD Pick-and-Place / episode 492 — fully successful
The robot, red cylinder, and black table tracks are usable. The graph changes
from the cylinder on the table to robot holding it and matches the visible
pickup sequence.

28 VIOLA / episode 0 — unsuccessful
Only the robot is retained. The black bowl, lazy Susan, and silver plate are all
rejected or absent, so the visible transfer cannot be grounded even though the

49 Bridge / episode 10144 — fully successful
The robot, potato, cutting board, and orange bowl are all correctly selected.
The final potato-inside-bowl relation and the action sequence are visually
coherent. This is the strongest result in the pilot.

60 PLEX RoboSuite / episode 109 — unsuccessful
The robot and table are retained, but both manipulated and target cube roles
are rejected. The stacking task therefore lacks its two essential object
tracks.

62 RoboSet / episode 10976 — unsuccessful
The source goal requests moving a banana into a bowl, while the selected clip
does not visibly contain that task. No banana candidate is found and the black
laptop is retained as the target. This remains a goal-video mismatch rather
than a segmentation-only failure.

Conclusion
----------
The no-box approach removes the expensive Qwen box-grounding pass and makes
each visual track-selection call short. It also provides useful rejection of
obviously invalid masks. However, single-pass binary visual pruning is too
conservative: it rejects valid supports, objects, targets, and one robot track.
The result falls from 7/1/2 on the current 10-scene best configuration to 2/2/6.
Therefore this experiment should not replace pipeline 6a92f266. A credible next
step would require AgentRVOS-style iterative reconsideration or a less brittle
selection policy, which is a material change rather than a small prompt fix.
