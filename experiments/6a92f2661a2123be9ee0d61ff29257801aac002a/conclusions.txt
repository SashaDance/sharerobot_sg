Method
------
The entity proposals, masks, DA3 outputs, and trajectories are copied unchanged
from the comparison experiment. Qwen predicts one compact timeline containing
initial state, inclusive action intervals, explicit state transitions, and final
state. A second all-frame visual pass verifies the draft, after which code
deterministically expands persistent state to every frame. The compact arrays
and prior-state conditioning are inspired by SceneGraphVLM, while the persistent
event/world state is inspired by WorldSGG and UNO. This is an adaptation to our
ontology, not a reproduction of those trained systems.

Automated result
----------------
The first run exposed a global schema ambiguity when EDAN produced the invalid
binary edge ``target on null``. The prompt was globally corrected to require a
valid object for binary relations and null only for unary open/closed state, and
all 11 scenes were rerun. The corrected graph, trajectory, render, and validation
stages completed with 11 successes and 0 failures. The validator also enforces
state replay, exact final-state agreement, valid entity references, and state
continuity across chunks for videos longer than 30 frames.

Verifier observation
--------------------
The second Qwen visual-verifier output was byte-equivalent to the draft event
graph in all 11 scenes. Thus the measured improvement comes from compact event
serialization and deterministic persistent-state expansion, not from the
current same-model verifier. Keeping that second call is not justified by this
pilot unless it is made genuinely independent or given a different verification
signal.

Conclusion
----------
With identical masks, persistent event inference improves the pilot from 2/7/2
to 7/2/2. It fixes the dominant relation/action failures without scene-specific
rules. The remaining failures require harder grounding changes: co-reference
for duplicate role nodes in ASU, single-instance trajectory selection in Clamp,
stable target grounding in FMB, and detection/reporting of goal-video mismatch
in RoboSet. Since these are no longer simple relation-prompt fixes, this round
stops here rather than adding episode-specific corrections.
